## Step 3: LimitInput 改修

### 目的
テキスト入力を+/-ボタンに変更し、確認・フィードバック機能を追加。

### 実装ファイル

#### 3.1 LimitInput コンポーネント改修
**ファイル**: `src/components/LimitInput.vue`

**実装内容**:

##### 3.1.1 インポート
- [ ] useToast インポート
- [ ] ConfirmDialog インポート
- [ ] useDrinkTracker から count も取得

##### 3.1.2 内部State追加
- [ ] pendingLimit: Ref<number | null>
- [ ] showConfirmDialog: Ref<boolean>
- [ ] confirmMessage: Ref<string>

##### 3.1.3 テンプレート改修
- [ ] 既存の input 要素削除
- [ ] `-` ボタン追加
  - [ ] クリック → decreaseLimit()
  - [ ] :disabled="limit === 1"
  - [ ] aria-label="目標を減らす"
- [ ] 目標本数表示エリア（"◯本"）
- [ ] `+` ボタン追加
  - [ ] クリック → increaseLimit()
  - [ ] aria-label="目標を増やす"
- [ ] ConfirmDialog 追加
  - [ ] :show="showConfirmDialog"
  - [ ] :message="confirmMessage"
  - [ ] @confirm="handleConfirm"
  - [ ] @cancel="handleCancel"

##### 3.1.4 メソッド実装
- [ ] **increaseLimit()**
  - [ ] newLimit = limit + 1
  - [ ] newLimit > 5 → Toast「飲み過ぎです」→ return
  - [ ] newLimit >= 3 → 確認ダイアログ表示
  - [ ] それ以外 → applyLimitChange()

- [ ] **decreaseLimit()**
  - [ ] newLimit = limit - 1
  - [ ] newLimit < 1 → return
  - [ ] count > newLimit → 確認ダイアログ表示
  - [ ] newLimit <= 2 → Toast「その調子！」
  - [ ] applyLimitChange()

- [ ] **handleConfirm()**
  - [ ] newLimit, oldLimit 取得
  - [ ] ダイアログ閉じる
  - [ ] applyLimitChange(newLimit)
  - [ ] 増加 && >= 3 → 爆発 + Toast「飲み過ぎ注意！」
  - [ ] 減少 && count > newLimit → Toast「既に超えています」
  - [ ] pendingLimit クリア

- [ ] **handleCancel()**
  - [ ] ダイアログ閉じる
  - [ ] pendingLimit クリア

- [ ] **applyLimitChange(newLimit)**
  - [ ] setLimit(newLimit)

- [ ] **triggerExplosion()**
  - [ ] App.vueの爆発エフェクトをトリガー
  - [ ] (既存のExplosionEffect連携方法を確認して実装)

##### 3.1.5 スタイル調整
- [ ] ボタンのスタイリング
  - [ ] サイズ・配置
  - [ ] hover/active状態
  - [ ] disabled状態
- [ ] 目標本数表示のスタイリング
- [ ] レスポンシブ対応

**参照**: 基本設計書 2.1

### 動作確認

#### 基本動作
- [ ] + ボタンで目標が増加
- [ ] - ボタンで目標が減少
- [ ] limit=1の時、-ボタンが無効化
- [ ] UIが既存デザインと調和

#### 上限チェック
- [ ] limit=5の時、+ボタンを押す
- [ ] Toast「飲み過ぎです」表示
- [ ] limit=5のまま（変更されない）

#### 3本以上への増加
- [ ] limit=2の状態で+ボタン
- [ ] 確認ダイアログ「本当に増やしますか？」表示
- [ ] 「いいえ」→ 変更なし
- [ ] 「はい」→ 爆発エフェクト → Toast「飲み過ぎ注意！」 → limit=3

#### 2本以下への減少
- [ ] limit=3の状態で-ボタン
- [ ] limit=2に変更
- [ ] Toast「その調子！健康的な選択です！」表示

#### 減少で超過ケース
- [ ] count=3, limit=4の状態を作る（飲むボタン3回+目標4に設定）
- [ ] -ボタン2回押下
- [ ] 1回目: limit=3（通常減少）
- [ ] 2回目: 確認ダイアログ「既に3本飲んでいますが、目標を2本に設定しますか？」
- [ ] 「はい」→ limit=2 → Toast「既に目標を超えています」
- [ ] 爆発エフェクトが出ないことを確認

### Git コミット
```
feat: LimitInputを+/-ボタン方式に改修

- テキスト入力を削除し+/-ボタンに変更
- 3本以上への増加時に確認ダイアログ表示
- 目標増加時に爆発エフェクト＆警告トースト
- 2本以下への減少時にポジティブトースト
- 減少で超過時の確認ダイアログ対応
```
